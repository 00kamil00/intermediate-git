# 🔀 Intermediate Git Practice

> A hands-on sandbox for mastering intermediate Git workflows and history management, built as part of **The Odin Project**.

## 📌 Overview
This repository serves as a practical playground for Git commands beyond standard `commit` and `push`. The goal was to build confidence in navigating history, reverting mistakes, and managing branches cleanly.

## 🛠️ What I Practiced
- **Reverting Changes:** Undoing specific commits safely using `git revert` while preserving history.
- **Branch Management:** Creating feature branches, merging, and understanding merge conflicts.
- **Commit Crafting:** Staging targeted changes, writing clear commit messages, and amending commits (`git commit --amend`).
- **History Exploration:** Inspecting tree states and changes using `git log --oneline --graph`.
